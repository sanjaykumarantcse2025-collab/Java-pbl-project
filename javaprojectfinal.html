Project Scope

ACADEMIC SIMULATION

This application demonstrates the security and access-control layers that would sit in front of a real VPN tunnel. It is not a kernel-level VPN and does not implement OpenVPN, WireGuard, production network tunnelling, or large-scale VPN infrastructure.
